# Ante Quem Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deployable static site where you place medieval manuscripts in time, built from the Bodleian's TEI catalogue, with a daily shared puzzle and an endless mode.

**Architecture:** A Python build step parses the medieval-mss tarball into four committed JSON files; a dependency-free static site consumes them. All rules that can be got wrong — deck legality, the difficulty ladder, scoring — live in Python and are pre-computed into `decks.json`, so the browser code stays presentational. One IIIF image is fetched per manuscript at play time and every crop is a local canvas operation.

**Tech Stack:** Python 3.12 stdlib only (`xml.etree`, `json`, `urllib` via `curl` subprocess), pytest for the build; vanilla ES modules and `node --test` for the site. No frameworks, no bundler, no runtime server.

**Spec:** `docs/specs/2026-09-09-design.md`

## Global Constraints

- **Never commit to the `rolls` repo.** This project is standalone.
- Python 3.12, standard library only. No pip dependencies in the build except `pytest` for tests.
- The site has zero runtime dependencies. No npm packages ship to the browser.
- **One IIIF image request per manuscript, ever.** All cropping is client-side canvas work. Bodleian's server timed out on ~1 in 5 requests during testing; any code path that blocks the player on a network fetch is a defect.
- Use only round IIIF widths: 400, 512, 600, 800, 1024. Never 341 or 420 — both reliably timed out.
- Image attribution (`CC BY-NC 4.0`, credit line from the manifest) must be visible wherever an image is shown.
- **Only time, region, and subject are ever guessed.** Owners, institutions, contents, bindings and bibliography are reveal-only.
- Date ranges are ranges. Never render a manuscript as having a single year.

## Deviations from the spec, and why

Two changes, both adopted deliberately:

1. **Crop focus is computed client-side, not at build time.** The spec called for sampling candidate crops per page at build time and storing the highest-variance one. That needs 2,260 image fetches against a server that fails 20% of the time (~45 min, fragile). The client already downloads the page image; one canvas pass picks the focus in milliseconds, is deterministic for a given image, and adapts if Bodleian replaces the scan. `puzzles.json` therefore carries no `focus` field.

2. **Daily decks are pre-built into `decks.json`.** The disjointness rule and the G(k) ladder are the two things most likely to be implemented wrongly. Generating 400 days of decks in Python, under pytest, means the browser never runs that logic for the daily mode. Endless mode deals client-side from the same rules, tested separately with `node --test`.

```python
# build/corpus.py
"""Fetch and locate the medieval-mss corpus."""
import subprocess, tarfile
from pathlib import Path

TARBALL_URL = "https://codeload.github.com/bodleian/medieval-mss/tar.gz/refs/heads/master"

def record_files(root: Path) -> list[Path]:
    """Every TEI record file. Excludes schemas (.rng) and the authority files at root."""
    return sorted(p for p in (root / "collections").rglob("*.xml") if p.is_file())

def corpus_root(cache_dir: Path) -> Path:
    """Download and extract the corpus if absent. Returns the extracted directory."""
    root = cache_dir / "medieval-mss-master"
    if root.is_dir():
        return root
    cache_dir.mkdir(parents=True, exist_ok=True)
    archive = cache_dir / "medieval-mss.tar.gz"
    if not archive.exists():
        subprocess.run(["curl", "-sSL", "-o", str(archive), TARBALL_URL], check=True)
    with tarfile.open(archive) as tf:
        tf.extractall(cache_dir, filter="data")
    return root
```

```python
# build/places.py
"""The place authority file, reduced to what the game needs."""
import xml.etree.ElementTree as ET
from dataclasses import dataclass
from pathlib import Path

NS = {"t": "http://www.tei-c.org/ns/1.0"}
XML_ID = "{http://www.w3.org/XML/1998/namespace}id"

# Ordered: first substring match wins. Derived from the measured distribution --
# England 35%, Italy 21%, Germany 16%, France 12%, everything else 16%.
_REGION_RULES = [
    ("England", ("england", "english", "britain", "wales", "scotland")),
    ("Italy",   ("italia", "italy", "italian", "roma", "venice", "florence", "milan")),
    ("Germany", ("deutschland", "german", "austria", "osterreich", "Österreich")),
    ("France",  ("france", "french", "paris", "flanders", "flemish", "netherlands",
                 "países bajos", "belgium")),
]

@dataclass(frozen=True)
class Place:
    id: str
    name: str
    lat: float
    lon: float

def region_for(name: str) -> str:
    low = (name or "").lower()
    for region, needles in _REGION_RULES:
        if any(n in low for n in needles):
            return region
    return "Elsewhere"

def load_places(root: Path) -> dict[str, Place]:
    """Place id -> Place, for the 659 places that carry coordinates."""
    tree = ET.parse(root / "places.xml").getroot()
    out: dict[str, Place] = {}
    for el in tree.iter("{http://www.tei-c.org/ns/1.0}place"):
        pid = el.get(XML_ID)
        geo = el.find(".//t:location/t:geo", NS)
        name_el = el.find("./t:placeName", NS)
        if not pid or geo is None or geo.text is None or name_el is None:
            continue
        parts = [p for p in geo.text.replace(",", " ").split() if p]
        if len(parts) < 2:
            continue
        try:
            lat, lon = float(parts[0]), float(parts[1])
        except ValueError:
            continue
        out[pid] = Place(pid, "".join(name_el.itertext()).strip(), lat, lon)
    return out
```

```python
# build/works.py
"""The work authority file's controlled subject vocabulary."""
import xml.etree.ElementTree as ET
from pathlib import Path

NS = {"t": "http://www.tei-c.org/ns/1.0"}
XML_ID = "{http://www.w3.org/XML/1998/namespace}id"

def load_subjects(root: Path) -> dict[str, list[str]]:
    """Work id -> subject slugs, from <term ref="#subject_x"/>. Untagged works are omitted."""
    tree = ET.parse(root / "works.xml").getroot()
    out: dict[str, list[str]] = {}
    for bibl in tree.iter("{http://www.tei-c.org/ns/1.0}bibl"):
        wid = bibl.get(XML_ID)
        if not wid:
            continue
        subs = [
            t.get("ref", "").lstrip("#").removeprefix("subject_")
            for t in bibl.findall("./t:term", NS)
            if t.get("ref", "").startswith("#subject_")
        ]
        if subs:
            out[wid] = subs
    return out
```

```python
# build/records.py
"""Turn one TEI msDesc into the flat Record the game consumes."""
import re
import xml.etree.ElementTree as ET
from dataclasses import dataclass, field
from pathlib import Path

from build.places import Place, region_for

NS = {"t": "http://www.tei-c.org/ns/1.0"}
T = "{http://www.tei-c.org/ns/1.0}"
XML_ID = "{http://www.w3.org/XML/1998/namespace}id"
CATALOGUE = "https://medieval.bodleian.ox.ac.uk/catalog/"
_UUID = re.compile(r"digital\.bodleian\.ox\.ac\.uk/objects/([0-9a-f-]{36})")

@dataclass
class Record:
    id: str
    shelfmark: str
    catalogue: str
    db_uuid: str | None
    not_before: int | None
    not_after: int | None
    date_display: str
    place_id: str | None
    place_name: str
    region: str
    subjects: list[str] = field(default_factory=list)
    language: str = ""
    material: str = ""
    hand: str = ""
    layout: str = ""
    decoration: list[str] = field(default_factory=list)
    owners: list[dict] = field(default_factory=list)
    acquisition: str = ""
    contents: list[str] = field(default_factory=list)

def _text(el) -> str:
    return " ".join("".join(el.itertext()).split()) if el is not None else ""

def _year(value: str | None) -> int | None:
    if not value:
        return None
    m = re.match(r"^(-?\d{1,4})", value)
    return int(m.group(1)) if m else None

def extract(path: Path, places: dict[str, Place], subjects: dict[str, list[str]]) -> list[Record]:
    root = ET.parse(path).getroot()
    tei_id = root.get(XML_ID) or ""
    out = []
    for ms in root.iter(T + "msDesc"):
        blob = ET.tostring(ms, encoding="unicode")
        origin_date = ms.find(".//t:history/t:origin//t:origDate", NS)
        origin_place = ms.find(".//t:history/t:origin//t:origPlace", NS)

        place_id, place_name = None, ""
        if origin_place is not None:
            for el in origin_place.iter():
                key = el.get("key")
                if key in places:
                    place_id, place_name = key, places[key].name
                    break
            if not place_name:
                place_name = _text(origin_place)

        work_keys = [t.get("key") for t in ms.findall(".//t:msContents//t:msItem/t:title", NS) if t.get("key")]
        subs: list[str] = []
        for key in work_keys:
            for s in subjects.get(key, []):
                if s not in subs:
                    subs.append(s)

        lang = next((t.get("mainLang") for t in ms.iter(T + "textLang") if t.get("mainLang")), "")
        mat = next((s.get("material") for s in ms.iter(T + "supportDesc") if s.get("material")), "")
        uuid = _UUID.search(blob)
        shelf = ms.find(".//t:msIdentifier/t:idno[@type='shelfmark']", NS)

        out.append(Record(
            id=tei_id or ms.get(XML_ID, ""),
            shelfmark=_text(shelf),
            catalogue=CATALOGUE + (tei_id or ""),
            db_uuid=uuid.group(1) if uuid else None,
            not_before=_year(origin_date.get("notBefore")) if origin_date is not None else None,
            not_after=_year(origin_date.get("notAfter")) if origin_date is not None else None,
            date_display=_text(origin_date),
            place_id=place_id,
            place_name=place_name,
            region=region_for(place_name),
            subjects=subs,
            language=lang,
            material=mat,
            hand=_text(ms.find(".//t:handDesc/t:handNote", NS)),
            layout=_text(ms.find(".//t:objectDesc/t:layoutDesc", NS)),
            decoration=[_text(d) for d in ms.findall(".//t:decoDesc/t:decoNote", NS) if _text(d)],
            owners=[
                {"name": _text(p), "role": p.get("role", "")}
                for p in ms.findall(".//t:history/t:provenance//t:persName", NS)
                if p.get("key") and _text(p)
            ],
            acquisition=_text(ms.find(".//t:history/t:acquisition", NS)),
            contents=[_text(t) for t in ms.findall(".//t:msContents//t:msItem/t:title", NS) if _text(t)][:6],
        ))
    return out

def playable(rec: Record) -> bool:
    """Dated, placed and illustrated. Measured at 2,260 of 11,123 records."""
    return bool(
        rec.not_before is not None
        and rec.not_after is not None
        and rec.not_after >= rec.not_before
        and rec.place_id
        and rec.db_uuid
    )
```

```python
# build/manifests.py
"""Resolve a Digital Bodleian object into one IIIF image service."""
import json, re, subprocess, time
from pathlib import Path

MANIFEST = "https://iiif.bodleian.ox.ac.uk/iiif/manifest/{}.json"
_TAGS = re.compile(r"<[^>]+>")

def pick_canvas(n: int) -> int:
    """A third of the way in: past the binding and flyleaves, into the text."""
    return max(0, min(n - 1, n // 3))

def parse_manifest(doc: dict) -> tuple[str, str] | None:
    canvases = (doc.get("sequences") or [{}])[0].get("canvases") or []
    if not canvases:
        return None
    canvas = canvases[pick_canvas(len(canvases))]
    try:
        resource = canvas["images"][0]["resource"]
    except (KeyError, IndexError):
        return None
    service = (resource.get("service") or {}).get("@id") or resource.get("@id")
    if not service:
        return None
    attribution = _TAGS.sub("", str(doc.get("attribution") or "")).strip()
    return service, attribution

def image_service(uuid: str, cache_dir: Path, tries: int = 4) -> tuple[str, str] | None:
    """Cached manifest fetch. Bodleian's server fails ~1 request in 5; retry."""
    cache_dir.mkdir(parents=True, exist_ok=True)
    cached = cache_dir / f"{uuid}.json"
    if cached.exists():
        try:
            return parse_manifest(json.loads(cached.read_text()))
        except json.JSONDecodeError:
            cached.unlink()
    for attempt in range(tries):
        proc = subprocess.run(
            ["curl", "-sS", "--max-time", "45", MANIFEST.format(uuid)],
            capture_output=True,
        )
        try:
            doc = json.loads(proc.stdout)
        except json.JSONDecodeError:
            time.sleep(2 * (attempt + 1))
            continue
        cached.write_text(json.dumps(doc))
        return parse_manifest(doc)
    return None
```

```python
# build/decks.py
"""Deck legality and daily deck generation.

Every rule that decides whether an answer is defensible lives here, in Python,
under test -- the browser never re-implements it for the daily mode.
"""
import random
from bisect import bisect_left

Card = tuple[str, int, int]  # (id, not_before, not_after)

GAP_START, GAP_FLOOR, GAP_DECAY = 300, 25, 0.75

def gap_for(round_index: int) -> int:
    """Minimum years between a new card and its neighbours, by round (1-based)."""
    return max(GAP_FLOOR, round(GAP_START * GAP_DECAY ** (round_index - 1)))

def _neighbours(board: list[Card], card: Card) -> tuple[Card | None, Card | None]:
    starts = [c[1] for c in board]
    i = bisect_left(starts, card[1])
    return (board[i - 1] if i > 0 else None, board[i] if i < len(board) else None)

def is_legal(board: list[Card], card: Card, min_gap: int) -> bool:
    """True when the card's range clears both neighbours by at least min_gap years."""
    before, after = _neighbours(board, card)
    if before is not None and card[1] - before[2] < min_gap:
        return False
    if after is not None and after[1] - card[2] < min_gap:
        return False
    return True

def build_deck(pool: list[Card], seed: str, length: int = 10) -> list[str]:
    """A deck whose every card is legal at the moment it is dealt.

    Stratified by century so the board does not jam in the 15th, which is 41%
    of the playable set.
    """
    rng = random.Random(seed)
    by_century: dict[int, list[Card]] = {}
    for card in pool:
        by_century.setdefault(card[1] // 100, []).append(card)
    for cards in by_century.values():
        rng.shuffle(cards)

    centuries = sorted(by_century)
    board: list[Card] = []
    chosen: list[str] = []
    for round_index in range(1, length + 1):
        min_gap = gap_for(round_index)
        candidates: list[Card] = []
        for century in rng.sample(centuries, len(centuries)):
            candidates.extend(by_century[century][:40])
        rng.shuffle(candidates)
        for card in candidates:
            if card[0] in chosen:
                continue
            if is_legal(board, card, min_gap):
                board.append(card)
                board.sort(key=lambda c: c[1])
                chosen.append(card[0])
                break
        else:
            # No card clears the gap at this rung; relax to the floor once.
            for card in candidates:
                if card[0] not in chosen and is_legal(board, card, GAP_FLOOR):
                    board.append(card)
                    board.sort(key=lambda c: c[1])
                    chosen.append(card[0])
                    break
            else:
                break
    return chosen

def build_daily_decks(pool: list[Card], days: list[str], length: int = 10) -> dict[str, list[str]]:
    return {day: build_deck(pool, seed=day, length=length) for day in days}
```

```python
# build/aggregates.py
"""Whole-corpus numbers the reveal panel quotes, and the look-alike index."""
from collections import Counter, defaultdict

from build.records import Record

def _bucket(rec: Record) -> tuple[str, int]:
    return (rec.region, (rec.not_before or 0) // 50 * 50)

def corpus_context(records: list[Record]) -> dict:
    regions = Counter(r.region for r in records)
    owners = Counter(o["name"] for r in records for o in r.owners if o.get("name"))
    subjects = Counter(s for r in records for s in r.subjects)
    languages = Counter(r.language for r in records if r.language)
    buckets = Counter(_bucket(r) for r in records)
    return {
        "total": len(records),
        "regions": dict(regions),
        "owners": dict(owners.most_common(60)),
        "subjects": dict(subjects),
        "languages": dict(languages),
        "buckets": {f"{region}|{half}": n for (region, half), n in buckets.items()},
    }

def lookalike_index(records: list[Record], k: int = 6) -> dict[str, list[str]]:
    """Six other manuscripts from the same region and half-century."""
    groups: dict[tuple[str, int], list[str]] = defaultdict(list)
    for rec in records:
        groups[_bucket(rec)].append(rec.id)
    out: dict[str, list[str]] = {}
    for rec in records:
        peers = [i for i in groups[_bucket(rec)] if i != rec.id]
        if len(peers) >= k:
            out[rec.id] = peers[:k]
    return out
```

```javascript
// site/crop.js

/** Fraction of the page shown at each expansion step. */
export const EXPANSION_STEPS = [0.14, 0.30, 0.58, 1.0];

/**
 * A square-ish crop of `zoom` fraction of the image, centred on (cx, cy) in
 * fractional coordinates and clamped to the image bounds.
 */
export function cropBox(imgW, imgH, cx, cy, zoom) {
  const w = Math.round(imgW * zoom);
  const h = Math.round(imgH * zoom);
  const x = Math.round(Math.min(Math.max(cx * imgW - w / 2, 0), imgW - w));
  const y = Math.round(Math.min(Math.max(cy * imgH - h / 2, 0), imgH - h));
  return { x, y, w, h };
}

/**
 * Pick the busiest cell of a gridN x gridN partition, by luminance variance.
 * Keeps the opening crop off blank parchment without any build-time work.
 */
export function focusPoint(imageData, gridN = 8) {
  const { data, width, height } = imageData;
  let best = { score: -1, gx: 0, gy: 0 };
  for (let gy = 0; gy < gridN; gy++) {
    for (let gx = 0; gx < gridN; gx++) {
      const x0 = Math.floor((gx * width) / gridN);
      const x1 = Math.floor(((gx + 1) * width) / gridN);
      const y0 = Math.floor((gy * height) / gridN);
      const y1 = Math.floor(((gy + 1) * height) / gridN);
      let sum = 0;
      let sumSq = 0;
      let n = 0;
      for (let y = y0; y < y1; y++) {
        for (let x = x0; x < x1; x++) {
          const i = (y * width + x) * 4;
          const lum = 0.299 * data[i] + 0.587 * data[i + 1] + 0.114 * data[i + 2];
          sum += lum;
          sumSq += lum * lum;
          n++;
        }
      }
      if (!n) continue;
      const variance = sumSq / n - (sum / n) ** 2;
      if (variance > best.score) best = { score: variance, gx, gy };
    }
  }
  return { cx: (best.gx + 0.5) / gridN, cy: (best.gy + 0.5) / gridN };
}
```

```javascript
// site/scoring.js

export const BASE = 1000;

/** Score multiplier by number of expansions spent. */
export const MULTIPLIERS = [1, 0.7, 0.45, 0.25];

/** A wrong placement scores nothing; a right one is discounted by what you looked at. */
export function scoreRound(expansionsUsed, correct) {
  if (!correct) return 0;
  const i = Math.min(Math.max(expansionsUsed, 0), MULTIPLIERS.length - 1);
  return Math.round(BASE * MULTIPLIERS[i]);
}
```

```javascript
// site/app.js
import { cropBox, EXPANSION_STEPS, focusPoint } from "./crop.js";
import { scoreRound, BASE } from "./scoring.js";
import { renderReveal } from "./reveal.js";

const DATA = "../data/";
const IIIF_WIDTH = 682;          // a pre-rendered size; never use 341 or 420
const PREFETCH_AHEAD = 3;

const state = {
  puzzles: new Map(), decks: null, context: null, lookalikes: null,
  mode: "daily", deck: [], index: 0, board: [], expansions: 0, score: 0,
  focus: { cx: 0.5, cy: 0.5 }, image: null, lives: 3,
};

const $ = (id) => document.getElementById(id);
const imageCache = new Map();

/** One request per manuscript, ever. Everything after this is local canvas work. */
function loadImage(puzzle) {
  if (imageCache.has(puzzle.id)) return imageCache.get(puzzle.id);
  const promise = new Promise((resolve, reject) => {
    const img = new Image();
    img.crossOrigin = "anonymous";
    img.onload = () => resolve(img);
    img.onerror = () => reject(new Error(`image failed: ${puzzle.id}`));
    img.src = `${puzzle.iiif}/full/${IIIF_WIDTH},/0/default.jpg`;
  });
  imageCache.set(puzzle.id, promise);
  return promise;
}

function prefetch() {
  for (let i = state.index + 1; i <= state.index + PREFETCH_AHEAD; i++) {
    const id = state.deck[i];
    if (id) loadImage(state.puzzles.get(id)).catch(() => {});
  }
}

function draw() {
  const canvas = $("view");
  const ctx = canvas.getContext("2d");
  ctx.fillStyle = "#efe9df";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  if (!state.image) return;
  const zoom = EXPANSION_STEPS[Math.min(state.expansions, EXPANSION_STEPS.length - 1)];
  const box = cropBox(state.image.width, state.image.height, state.focus.cx, state.focus.cy, zoom);
  const scale = Math.min(canvas.width / box.w, canvas.height / box.h);
  const dw = box.w * scale;
  const dh = box.h * scale;
  ctx.drawImage(state.image, box.x, box.y, box.w, box.h,
                (canvas.width - dw) / 2, (canvas.height - dh) / 2, dw, dh);
}

function detectFocus(img) {
  const c = document.createElement("canvas");
  c.width = 64;
  c.height = Math.max(1, Math.round((img.height / img.width) * 64));
  const ctx = c.getContext("2d", { willReadFrequently: true });
  ctx.drawImage(img, 0, 0, c.width, c.height);
  return focusPoint(ctx.getImageData(0, 0, c.width, c.height), 8);
}

function renderBoard() {
  const board = $("board");
  board.innerHTML = "";
  const slot = (i) => {
    const b = document.createElement("button");
    b.className = "slot";
    b.textContent = "▾";
    b.setAttribute("aria-label", `Place here, position ${i + 1}`);
    b.onclick = () => commit(i);
    return b;
  };
  board.append(slot(0));
  state.board.forEach((card, i) => {
    const el = document.createElement("div");
    el.className = "placed";
    el.innerHTML = `<strong>${card.date_display || `${card.not_before}–${card.not_after}`}</strong>
                    <span>${card.shelfmark}</span>`;
    board.append(el, slot(i + 1));
  });
}

function currentPuzzle() {
  return state.puzzles.get(state.deck[state.index]);
}

function commit(slotIndex) {
  const card = currentPuzzle();
  const trueIndex = state.board.filter((c) => c.not_before < card.not_before).length;
  const correct = slotIndex === trueIndex;
  const gained = scoreRound(state.expansions, correct);
  state.score += gained;
  $("score").textContent = state.score;

  if (correct) {
    state.board.push(card);
    state.board.sort((a, b) => a.not_before - b.not_before);
  } else {
    state.lives -= 1;
  }
  renderBoard();
  renderReveal($("reveal"), card, {
    correct, gained,
    context: state.context,
    lookalikes: (state.lookalikes[card.id] || []).map((id) => state.puzzles.get(id)).filter(Boolean),
    onNext: next,
  });
}

async function next() {
  $("reveal").hidden = true;
  state.index += 1;
  state.expansions = 0;
  if (state.lives <= 0 || state.index >= state.deck.length) return finish();
  await showCard();
}

async function showCard() {
  const puzzle = currentPuzzle();
  if (!puzzle) return finish();
  $("credit").textContent = puzzle.attribution || "";
  $("expand-cost").textContent = "";
  state.image = null;
  draw();
  try {
    state.image = await loadImage(puzzle);
    state.focus = detectFocus(state.image);
  } catch {
    return next();   // a dead image must never stall the run
  }
  draw();
  renderBoard();
  prefetch();
}

function finish() {
  $("stage").hidden = true;
  $("board").hidden = false;
  const done = document.createElement("p");
  done.className = "done";
  done.textContent = `${state.board.length} placed · ${state.score} points`;
  $("board").append(done);
}

$("expand").onclick = () => {
  if (state.expansions >= EXPANSION_STEPS.length - 1) return;
  state.expansions += 1;
  const next = Math.min(state.expansions, 3);
  $("expand-cost").textContent = `(${Math.round((scoreRound(next, true) / BASE) * 100)}%)`;
  draw();
};

async function boot() {
  const [puzzles, decks, context, lookalikes] = await Promise.all(
    ["puzzles", "decks", "context", "lookalikes"].map((n) =>
      fetch(`${DATA}${n}.json`).then((r) => r.json())));
  puzzles.forEach((p) => state.puzzles.set(p.id, p));
  Object.assign(state, { decks, context, lookalikes });
  const today = new Date().toISOString().slice(0, 10);
  state.deck = decks[today] || Object.values(decks)[0];
  await showCard();
}

boot();
```

```javascript
// site/reveal.js

/** Everything the catalogue knows, plus what only the whole corpus can say. */
export function renderReveal(el, card, { correct, gained, context, lookalikes, onNext }) {
  const owners = card.owners?.map((o) => o.name).filter(Boolean) ?? [];
  const corpus = [];
  if (context?.regions?.[card.region]) {
    corpus.push(`${context.regions[card.region]} manuscripts here were made in ${card.region}.`);
  }
  for (const name of owners.slice(0, 1)) {
    const n = context?.owners?.[name];
    if (n > 1) corpus.push(`${name} owned ${n} of the manuscripts in this game.`);
  }

  el.hidden = false;
  el.innerHTML = `
    <p class="verdict ${correct ? "right" : "wrong"}">
      ${correct ? "Correct" : "Not quite"} · ${gained} points
    </p>
    <h2>${card.shelfmark}</h2>
    <p class="when">${card.date_display || `${card.not_before}–${card.not_after}`}${
      card.place_name ? `, ${card.place_name}` : ""}</p>
    ${card.contents?.length ? `<p class="contents">${card.contents.join("; ")}</p>` : ""}
    ${card.hand ? `<blockquote class="hand"><h3>The hand</h3>${card.hand}</blockquote>` : ""}
    ${card.decoration?.length ? `<p class="deco">${card.decoration.join(" ")}</p>` : ""}
    ${owners.length ? `<p class="owners"><strong>Owned by</strong> ${owners.join(" → ")}</p>` : ""}
    ${card.acquisition ? `<p class="acq">${card.acquisition}</p>` : ""}
    ${corpus.length ? `<ul class="corpus">${corpus.map((c) => `<li>${c}</li>`).join("")}</ul>` : ""}
    ${lookalikes.length ? `<div class="lookalikes"><h3>Others like it</h3><div class="strip">${
      lookalikes.map((p) => `<img loading="lazy" src="${p.iiif}/full/170,/0/default.jpg" alt="${p.shelfmark}">`).join("")
    }</div></div>` : ""}
    <p class="links">
      <a href="${card.catalogue}" target="_blank" rel="noopener">See the catalogue record</a>
      <a href="${card.digitalBodleian}" target="_blank" rel="noopener">All images</a>
    </p>
    <button id="next-round">Next</button>`;
  el.querySelector("#next-round").onclick = onNext;
}
```
